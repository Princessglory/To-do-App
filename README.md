## Introduction
A simple and interactive to-do list application built with HTML, CSS, and JavaScript. This app allows users to manage daily tasks with essential features such as adding, editing, completing, deleting, and filtering tasks.

## Features
- Add Tasks – Easily add new tasks to your list.
- Mark as Completed – Toggle tasks between completed and active.
- Delete Tasks – Remove tasks you no longer need.
- Filter View – Switch between All, Active, and Completed tasks.
- Categorize tasks for better organization.
- Responsive design for use on desktop and mobile devices.
- Persistent Storage – Your tasks are saved even after a browser refresh.

## Installation
1. Clone the repository:
    ```bash
    git clone https://github.com/Princessglory/To-do-App.git
    ```
2. Navigate to the project directory:
    ```bash
    cd To-do-App
    ```
3. Open index.html in your browser to start using the app.


## Usage
1. Open the application in your browser.
2. Add tasks by typing in the input field and clicking the "Add" button.
3. Mark tasks as completed by checking the checkbox next to them.
4. Edit or delete tasks using the respective buttons.
5. Filter tasks by clicking on all, active or completed button.
